# Как поставить StudApp на iPhone через Mac

Понадобятся Mac, iPhone, кабель и Apple ID (тот же, что в App Store). Платить ничего не нужно.

## 1. Один раз подготовить Mac

1. Откройте **App Store** на Mac, найдите **Xcode** и нажмите «Загрузить». Он большой (несколько гигабайт), скачивание может занять час.
2. Запустите Xcode один раз. Если он предложит доустановить компоненты (Install / Установить), согласитесь. Когда спросит про платформы, отметьте **iOS**.
3. Скачайте **Node.js** с сайта https://nodejs.org: большая зелёная кнопка с пометкой **LTS**. Откройте скачанный файл `.pkg` и нажимайте «Продолжить» до конца.
4. Добавьте Apple ID в Xcode. В верхнем меню: **Xcode → Settings… (Настройки) → Accounts → «+» внизу слева → Apple ID**, затем введите почту и пароль.

## 2. Скачать проект и собрать приложение

1. Откройте программу **Терминал**: нажмите `Cmd + Пробел`, введите «Терминал» и нажмите Enter.
2. Вставьте по очереди эти строки. После каждой нажимайте Enter и ждите, пока снова появится строка ввода:

   ```
   git clone https://github.com/Aliantpt/studapp.git
   cd studapp
   npm ci
   npm run ios
   npx cap open ios
   ```

   Первая строка скачивает проект, третья ставит нужные библиотеки (около минуты), четвёртая собирает приложение. Последняя строка открывает проект в Xcode.

   Если на первой строке Mac предложит установить «инструменты командной строки», нажмите «Установить» и после установки повторите эту строку.

## 3. Подписать приложение своим Apple ID

1. В Xcode слева нажмите на самый верхний синий значок **App**.
2. В середине окна выберите **TARGETS → App** и откройте вкладку **Signing & Capabilities**.
3. Поставьте галочку **Automatically manage signing**.
4. В поле **Team** выберите своё имя с пометкой **(Personal Team)**.
5. Если появилась красная ошибка про **Bundle Identifier**, допишите в конец этого поля что-нибудь своё, например `io.github.aliantpt.studapp.sfhn`.

## 4. Поставить на iPhone

1. Подключите iPhone к Mac кабелем. На телефоне нажмите **«Доверять»** и введите код-пароль.
2. Включите на iPhone режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика → включить**. Телефон перезагрузится, после этого подтвердите включение. Если этого пункта нет, сначала выполните шаг 3 ниже один раз, и пункт появится.
3. В Xcode вверху посередине нажмите на название устройства и выберите **свой iPhone**. Затем нажмите треугольник **▶** слева вверху.
4. Первый запуск iPhone не пустит. Откройте на телефоне **Настройки → Основные → VPN и управление устройством**, нажмите на свой Apple ID и выберите **«Доверять»**.
5. Снова нажмите **▶** в Xcode, и StudApp откроется на телефоне. Дальше его можно запускать с иконки, как обычное приложение.

## Что важно знать

- **Бесплатная подпись действует 7 дней.** Потом приложение перестанет открываться. Подключите телефон, откройте проект в Xcode (`cd studapp`, затем `npx cap open ios`) и снова нажмите ▶. Данные внутри при этом сохраняются.
- **Данные приложения и сайта разные.** Задания, расписание и сканы с сайта в приложение сами не переедут, их нужно завести заново.
- **Напоминания в приложении приходят даже при закрытом приложении:** их ставит сама iOS. При первом напоминании телефон спросит разрешение на уведомления, ответьте «Разрешить».
- При первом скане телефон спросит доступ к камере и фото. Это нужно, чтобы снимать и выбирать снимки.

## Как обновить приложение до новой версии

В Терминале:

```
cd studapp
git pull
npm ci
npm run ios
npx cap open ios
```

Затем подключите iPhone и нажмите ▶ в Xcode.
