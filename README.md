# StudApp

Помощник студента: планер домашних заданий с напоминаниями, расписание,
сканер учебных материалов и ИИ-ассистент, работающий прямо на устройстве.

Сейчас это веб-приложение (PWA), которое открывается в браузере и
устанавливается на главный экран телефона. Позже из этого же кода
соберём приложения для App Store и Google Play.

**Открыть приложение:** https://aliantpt.github.io/studapp/

## Как устроен проект (для любопытных)

- `src/` — код приложения (React + TypeScript).
- `public/` — иконки и другие файлы, которые попадают на сайт как есть.
- `.github/workflows/deploy.yml` — инструкция для GitHub: как собрать
  приложение и выложить его на GitHub Pages после каждого изменения.

Запуск на компьютере для разработки: `npm install`, затем `npm run dev`.
